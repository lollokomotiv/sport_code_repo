# Prototipi

Script usa e getta delle prove: ognuno risponde a una domanda di una issue e lì sta il
risultato. Non fanno parte dell'app, non hanno test, hanno percorsi scritti a mano e
leggono dati privati in `data/` e `output/`, fuori da git.

| Script | Issue | Domanda |
|---|---|---|
| `tracker_13.py` | #13 | quanta palla trova il tracker, e quante rilevazioni sono davvero la palla |
| `richiamo_13.py` | #13 | il tracker vede la palla sui tocchi etichettati a mano? |
| `campo_19.py` | #19 | calibrazione del campo dal colore e dalle righe |
| `scambi_19.py` | #19 | scambi trovati dal tracker contro quelli etichettati |
